# 模型能力与样片验收

用户成功基准是ChatGPT Image首帧＋即梦Seedance视频。当前JoyAI Plus BF16和H3是本地候选组合，尚无本项目样片证明达到相同效果。

|要求|实现与实际验收|
|---|---|
|双猫身份、场景、机位|真实多图传入JoyAI，40步/CFG4；检查脸、花纹、体型、左右站位、道具和起势|
|确认服装|身份和服装用途分开；检查颜色、长度、腰边、褶裥、尾巴出口，抬爪时不消失或融入毛发|
|微表情与爪动作|H3首帧＋文字分段；检查顺序、反应和肢体可辨；不承诺逐秒逐爪精确卡点|
|嘴部和声音|逐猫策略和逐镜音频；检查静音不额外开口，对白／唱歌来自正确角色|
|动作视频、原舞曲|当前没有这类输入；不能写已参考，需要时另提方案，不自动追加权重或API|
|镜间精确接帧|目前画面独立，可共享场景和服装；下一镜首帧不等于上一段实际尾帧|

官方资料用于判断候选是否适配，不证明本项目效果：[JoyAI多图能力](https://github.com/jd-opensource/JoyAI-Image)、[H3原生输入和时长](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-native)、[H3提示词格式](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-prompt-guide)。

结构验证和样片验收分开。先预检节点、模型文件、资产、参数和提示词，再由用户在同一正式图选少量镜号生成。初始model_quality=pending，不存在自动画质分数、实测耗时或显存结论。只有用户明确看片通过才选accepted；失败选rejected，记录具体哪项失败并停止全量。

查看开头、中段动作、抬爪／遮挡和结尾。身份、肢体、服装或动作顺序错误属于失败，小幅时间偏差可接受。服装无真实参考时只能测试文字约束，不能把该结果说成服装参考已验证。修正可见问题对应的素材、姿态、动作复杂度和提示词，不无限叠禁止词。
