# 审稿与修改

用于检查提案、完整稿和用户反馈。要有判断、有证据、有改法，不把清单变成固定打分仪式。

## 先判断问题在哪一层

| 层次 | 典型症状 | 优先改什么 |
| --- | --- | --- |
| 创意前提 | 只有“猫做某事”，看不出为什么值得看 | 换欲望关系、处境或规则，提出不同故事方向 |
| 人物动机 | 为反转突然变坏、突然聪明，或谁都没有自己的打算 | 找具体目标、代价和策略，补选择而不是补身世 |
| 冲突发展 | 同样的失败重复，事件之间只有“然后” | 改一次回应及其后果，让后续办法被迫变化 |
| 关系互动 | 人只有抱猫、夸猫、给东西，或猫只等人解决 | 给弱的一方一个会改变条件的行动 |
| 事件表达 | 有情绪词没行动，有多地点没事件 | 写清具体行为与因果，保留有效主线 |
| 节奏 | 起头绕太久，高潮没看懂就结束 | 调整信息和反应时间，合并无作用重复 |

先指出最影响故事的一两个问题。剧情根本不成立时，不优先润色台词或堆砌环境形容词。

## 用证据审稿

每条重要判断写成：具体位置 → 观众会遇到的问题 → 可能原因 → 可执行的改法。

例如：“第二次把杯子推回去与第一次没有条件变化，观众已知道猫不肯喝。可以让人把杯子放到约定的边界外，猫必须决定是否破坏自己先提出的规则。”不要只说“张力不足，加强冲突”。

| 检查维度 | 找什么证据 | 不足时的修法 |
| --- | --- | --- |
| 核心吸引力 | 能指出一组具体欲望碰撞或一个值得等待的问题 | 先重写一句话故事，再改剧情 |
| 独特性 | 某个关键行动依赖这个猫、这个人或这个场合 | 加入会改变策略的差异，别只加背景描写 |
| 双方主动性 | 人与猫都做过改变下一步的选择 | 让回应带来新条件，避免由一方包办所有聪明 |
| 因果与升级 | 后一个办法承接前一个后果 | 合并重复，补漏掉的动作或代价 |
| 场景与事件 | 不同空间改变行动、信息或关系 | 替换无作用的地点变化，让环境参与事件 |
| 可读性 | 读者能跟上目标、关键道具与变化 | 补足必要行动、线索或反应，删冗余解释 |
| 回报 | 结尾回答开头的期待，且前文有依据 | 补铺垫或重选结尾，别临时送来救星 |
| 情绪与口味 | 具体哪次选择让人笑、紧张或在乎 | 对照用户偏好，避免替用户宣布“感动” |

若用户要评分，可以用“明确成立／部分成立／尚未成立”并附证据；数字评分只能是编辑主观判断，不能称为平台表现预测。

## 六个快速试验

1. **换角色**：把猫替换成人，哪一处必须重写？若没有，找猫真正参与故事的方式。
2. **换地点**：地点名全换仍不影响行动吗？若是，选一个能改变办法的环境条件。
3. **删一场**：删掉后目标、信息、关系和节奏全不变吗？若是，考虑删或并。必要的呼吸段落可以靠节奏价值保留。
4. **因果倒查**：从高潮往前追，决定、筹码、能力或线索何时建立？没有则补或换。
5. **去解释**：暂时拿掉解释旁白，基本发生了什么是否仍能理解？必要对白可保留；无需把所有故事变成默片。
6. **看双方**：将猫和人的行动分两列，哪一方始终只有反应？给其自己的计划。

## 根据反馈改写

- **“再有创意一点”**：先指出目前可预测在哪里，提供两种实质改变，如换信息关系或让主角更主动。明确各自会改变什么；别只换形容词。
- **“再大胆一点”**：若程度含糊，给有代价的具体选项。默认从角色策略和规则后果推远；新世界观、突然变类型或改已定结尾前先说明并确认。
- **“冲突再强一点”**：提高对方应对的聪明程度、选择的代价或任务限制。保持动机可信，强度不等于音量、羞辱或恶意。
- **“互动再多一点”**：新增双方改变对方计划的回合，优先替换无作用片段；不机械增加摸头和对白句数。
- **“场景再丰富一点”**：检查新地点能提供什么事件条件，再提出空间、行动或线索的改法。若用户要的是摄影或分镜变化，明确属于导演工作，不用改剧情假装解决拍法问题。
- **“只改这里”**：复述保留项，给替换段落，核对相邻铺垫和后果。影响到重要已定内容时说明选择，不静默重写整篇。

## 简短剧情审稿的默认写法

保留一项最强设计；指出一项最可能失效的地方；给出具体修法或需要用户判断的口味差异。不要每稿都附一页全绿评分表。

区分“写得能理解”和“已经好看”。作者自己跑通逻辑不等于读者被打动；用户反馈才校准口味，成片才验证表演和节奏。
