# 审图、看片与局部修订

质量判断按结果进行。文字完备、首帧好看、动作成立和整段吸引人是不同层次，不能相互替代。

## 文案先检查

1. 定稿事件、对白和结尾有没有遗漏、偷换或提前揭示。
2. 素材是否真实提供，角色与用途是否正确，平台参数是否已核实。
3. 首帧起点、视频第一动作和本镜终点是否相容。
4. 人猫接触、重心、道具归属、轴线、视线和照明是否连续。
5. 动作与台词能否在实际时长内完成，是否留有必要反应。
6. 每镜是否承担观看任务，整段是否有层次、变化和回报。

对首帧已经揭开道具、视频却要求从未揭开开始的稿，直接修状态冲突。对“固定镜头同时向前推进”的稿，明确选定其中一种或分阶段改写，不把矛盾交给模型猜。

## 首帧验收

查看用户实际返回的图，指出具体可见位置：哪个角色、哪个肢体、哪件衣服、哪处空间或光线。检查身份、服装、比例、落地支撑、接触阴影、关键道具、视线和动作余地。

首帧若已执行完主要动作，应回到正确起点；除非用户明确接受改动，否则不通过反写视频来将错就错。图像存在手爪融合、脸部漂移或重要遮挡时，先修图再谈视频动作。

## 视频验收

用具体时间点或动作阶段描述偏差：预期是什么，实际看见什么，影响哪一个剧情或导演目的。只收到用户文字描述时写“按你的反馈”，不声称看到了不存在的视频。

| 问题 | 优先诊断 | 常用修法 |
| --- | --- | --- |
| 身份／服装漂移 | 首帧是否正确，输入用途是否混淆，动作是否遮住关键特征 | 修首帧或参考绑定，保留关键身份约束；不重写全部摄影 |
| 动作不发生或被重复 | 起点是否错误，动作顺序是否含糊，事件是否过载 | 对齐起点，写清先后与停止条件，必要时拆镜 |
| 接触穿模、抓错道具 | 两者距离、支撑和归属是否清楚 | 重做接触构图与动作链，保留要表达的互动 |
| 运镜漂浮或互相冲突 | 是否同时下达多条矛盾路径，相机是否穿越实体 | 简化到清楚路径，或拆成合理切镜；不默认全部改平拍 |
| 表演过头、嘴部乱动 | 情绪标签是否代替行动，嘴部要求是否冲突 | 写触发点与克制的具体行为，按台词／叼物／安静状态区分 |
| 声音不对、对白不完整 | 平台能力、说话者、时机、余量是否明确 | 保留对白原文，调整节拍或长度；需后期时明确说明 |
| 单镜好看但剪不起来 | 位置、方向、道具、时间与光线是否接上 | 修相邻镜头或补必要关系镜头，不修改无关镜头 |
| 全片平淡或炫技 | 是否每镜重复同种观看距离、节奏或运动，注意力是否落错位置 | 回到观众信息与人物选择，重新安排镜头重点 |

## 一次修订怎样交付

给出简短诊断、修订的完整复制块、保持不变项和受影响镜号。用户只改一镜时，不重写整套；但必须指出其变化是否影响前后衔接。

优先修改最能解释失败的因素。一次同时改服装、景别、动作和灯光，难以判断哪项有效；若问题需要整镜重设计，直接说明原因，保留剧情目的。

需要降低复杂度时保留本镜最重要的观众体验。例如把难以稳定完成的穿行环绕换成遮挡后横移揭示，仍应让观众在正确时机看见新信息，不能只留下角色站着。

## 验收措辞

- “文案已核对”：说明检查了哪些冲突与连续性。
- “首帧已审”：必须看过用户提供的实际首帧，并说明尚存问题或接受范围。
- “视频已审”：必须看过实际视频或明确仅依据用户反馈；记录动作、摄影与声音是否达成意图。
- “整段可用”：需要把相邻片段一起判断节奏与衔接；不能只凭单张好图宣布。

不用主观分数预测流量。对“是否足够吸引人”的判断，说明具体哪次揭示、互动或反应有效，以及用户还需要判断的口味差异。没有实际生成结果时，交付设计与验证方法即可，不宣称达到电影成片或行业排名。
