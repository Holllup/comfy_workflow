# ChatGPT 首帧图提示词

首帧是一个连续镜头的起点。它既要好看，也要允许下一步动作自然发生。

## 写之前先解决

1. 本镜观众先注意谁或什么，关键动作尚未发生到哪一步。
2. 本镜实际附哪些图，分别控制身份、服装、环境还是视觉风格。
3. 猫、人、道具与机位的位置是否支持接下来的接触、移动和运镜。

用户未提供的身份、衣服或场景图片不能登记为已附入。身份或服装存在关键歧义时先询问；没有场景图但剧情已明确的空间，可以写文字设计并说明其依据，不要求所有镜头必须有场景参考。

## 完整信息如何组织

用自然中文分段，按复杂度合并；不以固定字数或每项都写满为目标。

| 信息 | 应写清的内容 | 容易出错的地方 |
| --- | --- | --- |
| 成像目标 | 一张静态图、画幅、真实摄影与本镜观看重点 | 写“电影感、8K”却无构图和照明 |
| 参考绑定 | 本次图 1／图 2 的具体用途、哪些细节要继承 | 把外貌参考的衣服、背景、站姿一起误继承 |
| 人物与服装 | 可辨认外貌、体型比例、逐角色穿着、饰品归属 | 裸身身份图取消已确认服装，或服装互换 |
| 场景与空间 | 主要地标、道具位置、人物距离及前后景 | 只列“桌子、门、窗”，没有相对关系 |
| 起始状态 | 支撑、重心、手爪、道具接触、视线和嘴部 | 首帧已经完成视频里才要发生的事 |
| 摄影 | 机位高度、朝向、景别、主体位置、透视与焦点层次 | “近景”同时要求全屋、全身和极小道具都清楚 |
| 光色与材质 | 光源方向、软硬、主次明暗、环境色、接触阴影 | 人猫各自受不同方向的光，毛发像塑料 |
| 保持项 | 本镜真正重要的身份、服装、空间与构图限制 | 从别的作品复制大量不适用禁令 |

摄影规格作为外观线索，不能承诺模型准确模拟某个光学参数。重点是描述“前景的手清楚，后方猫仍可辨认其反应”等实际观看结果。

## 静态状态与动作空间

选择动作发生前的可读瞬间，不一定是所有角色僵直站立。爪可以悬在将要碰到的位置，人物可以已转身准备迈步，但不能在一张图里要求“先伸手、再拿起、最后放下”。

构图给动作方向留空间，给手爪与道具留辨认余地。未来要向右走的人不能毫无原因地被贴在右画框边；未来才揭开的信息不要在首帧中央提前展示。

允许部分遮挡以服务叙事，但关键接触如果连开始关系都无法辨认，应调机位或先补关系镜头。

## 可复制写法示意

以下只是写作组织方式，正式稿必须填成具体内容，不保留空模板：

> 生成一张横屏 16:9 的真实摄影静态首帧。说明这张图的主要观看重点。  
> 本次附图的编号、身份／服装／场景用途及继承优先级。  
> 地点、时间和光源；人猫与关键道具的相对位置。  
> 两个角色此刻的姿态、手爪、视线与动作开始条件。  
> 相机位置、景别、透视、焦点和前后景层次。  
> 本镜必要的材质、保持项和排除项。

把对白、事件发展、运镜路径和结束状态写入视频块或导演说明，不塞进静态图块。故事需要可读文字时保留并逐字核对；无此需求时再说明不添加额外文字。不要无条件删除剧情依赖的文字。

## 审图与修图

查看实际图后核对：身份与服装、比例和支撑、空间与道具、手爪接触、观看重点、光线、起始状态。漂亮但不支持动作的图仍需修。

修图指令采用“只调整什么＋保留什么”，以用户实际返回的图为编辑输入。修改机位或起始姿态会影响整镜，需要同步核对视频文本；只修衣服颜色通常不需要重编剧情或镜头。

仅用文字说“保持一致”不能作为一致性已经实现的证据。尚未查看图片时只能交付首帧提示词或审图要点。
