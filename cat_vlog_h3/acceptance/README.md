# JoyAI/H3少量样片验收

这是一组待运行的固定验收案例，不是已跑过的结果。用同一正式图，将acceptance_story.json全文粘进story_json，新run_id例如cat_v4_acceptance_01，selected_shots=1,4,7，model_quality=pending。阶段1出三张图供审查；通过后阶段2出三段视频。不要在这份技术验收稿中直接all生成正式一期，正式舞蹈稿另用新的run_id。

|镜号|目标与实际时长|必须看懂|
|---|---|---|
|1|单猫身份与举爪，124帧/5.167秒|猫脸花纹、正常爪、举后收回、固定机位、闭嘴|
|4|双猫三动作慢练，141帧/5.875秒|左右角色不交换，室友先动主角略迟跟随，双爪收胸→单爪斜举→双爪侧展→收回；背景人类可以自然存在|
|7|轻微神态与友情反应，192帧/8秒|低头→抬眼→耳眼放松，避免张大嘴、过度夸张或持续僵硬|

逐项记录accepted/rejected/pending，并写具体帧或时刻，勿填自动画质分数。身份、猫肢体、爪融合、动作顺序、嘴部或场景跳变属于关键失败；小幅时间或动作幅度偏差可接受。查看起点、中段抬爪／遮挡和结尾。脚本只能验证帧数与字段，不能代替看片。

在sample_review_template.json填实际输出路径、耗时、显存（能测到时填写）和具体失败。不运行就保持null/pending。三例通过后可在正式分镜中model_quality=accepted；失败选rejected停止视频生成，先针对问题修图、状态、素材用途或动作要求。

**服装参考尚未测试。** 当前没有用户确认的服装照片，案例不虚构粉裙或服装图。未来需要服装时，先把实际服装图复制进assets并注册purpose=wardrobe、owner为对应图库，再指定characters.wardrobe。使用裸身身份照＋确认服装图，检查颜色、长度、腰边、褶裥与尾巴出口，尤其看举爪中段有无消失。没有实际照片时只能测文字衣服约束，不能宣布服装参考通过。

场景照片同样先注册真实资产再选择；缺图预检应报错。动作视频或原曲目前没有接入，案例只使用文字动作与原生声画；不承诺精准卡点或原曲复现。
